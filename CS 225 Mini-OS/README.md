# CS 225 Mini-OS

CS 225 Mini-OS is a Smart Emergency Response Center simulation implemented in C. It demonstrates process management, CPU scheduling, memory allocation, inter-process communication, deadlock handling with Banker's Algorithm, and operational logging. The repository includes both a command-line version and a Raylib-based GUI version.

The [CLI version](./CLI%20Version/mini-os/README.md) focuses on the interactive console workflow, while the [GUI version](./GUI%20Version/mini-os/README.md) adds a visual dashboard for the same core operating-system concepts.
